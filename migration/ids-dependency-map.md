# 剩余功能与真实 IDS 会话依赖

## 直接依赖真实 IDS

这些功能可以离线完成代码、解析器、缓存和 UI，但真实数据验收必须取得有效 IDS Cookie：

- IDS 登录、滑块、角色识别、会话续期与重启恢复；
- 学期信息、课表、成绩、考试、空闲教室；
- 课堂考勤的超星 SSO；
- 校园卡余额、流水和付款二维码；
- 宿舍电量、用水和历史数据中的 `EnergySession` 部分；
- 图书馆借阅、逾期、续借和用户信息；公共馆藏搜索不依赖 IDS；
- 其他实验/实验课表 `SysjSession`；
- 使用 Ehall 单点登录的缴费、报修、空间预约等 Web 入口。

## 不依赖 IDS，但需要其他外部条件

- 宿舍饮水：独立手机号、图片验证码和短信验证码；
- 校园网：校园网络环境及可选独立密码；
- 体育课、打卡、体测：独立体育系统密码；
- 物理实验及实验报告：独立实验系统凭据，部分接口要求校园网；
- 空调能耗：独立 IMEI；
- 睿思：独立论坛账号和验证码；
- 通知、系统日历、桌面卡片：实现本身不需要 IDS，但使用真实课表做端到端验收时需要 IDS 数据。

## 完全可独立推进

- 自定义课程和本地设置；
- 主题、三语言、缓存、日志、排序、隐藏和恢复；
- Pig/Dashboard、XDU Planet、更新通知、公开公告；
- 图书馆公共检索；
- 五栏导航、页面返回栈、设计 token 和非登录页面 UI 对齐；
- 网络错误、空数据、超时、权限拒绝和本地单元测试。

当前首页外壳把多数入口放在登录之后，这只是现有导航限制，不表示独立服务本身依赖 IDS。
独立切片应增加安全的开发/测试入口或组件级测试，但不得静态伪造 IDS 登录成功。
